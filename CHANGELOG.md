## [v0.3.0] - 2026-10-07

### Highlights

- **Session recovery**: `omnidevx sessions` lists your Claude Code and Codex CLI sessions with state and title, shows one in detail, and resumes it in its original directory

### Added

- `omnidevx sessions` lists sessions newest first with filters for directory, harness, state, and recency, plus `--json`, `--all`, and `--no-content` ([`00fd30e`](https://github.com/plexusone/omnidevx/commit/00fd30e))
- `omnidevx sessions show <id>` prints one session's directory, branch, timestamps, state, recent prompts, and resume command ([`00fd30e`](https://github.com/plexusone/omnidevx/commit/00fd30e))
- `omnidevx sessions resume <id>` runs the agent's own resume command from the session's directory, refusing a running session unless `--force` is given and stopping if the directory is gone, with `--print` to show the command instead ([`00fd30e`](https://github.com/plexusone/omnidevx/commit/00fd30e))
- Session catalog composing the Claude Code and Codex CLI readers, with unique-prefix ID resolution and a failing reader no longer hiding the other's sessions, re-exported from the top-level package ([`683b0f5`](https://github.com/plexusone/omnidevx/commit/683b0f5))
- Resume works on Windows by running the command as a child process, and the directory filter compares cleaned paths on both sides ([`d98795a`](https://github.com/plexusone/omnidevx/commit/d98795a))

### Changed

- Migrated the `omnidevx` CLI to Cobra, preserving the `collect` and `version` commands ([`00fd30e`](https://github.com/plexusone/omnidevx/commit/00fd30e))

### Fixed

- `omnidevx version` reports the build version from `-ldflags`, else the module version embedded by `go install`, else `dev`, instead of a fixed `v0.1.0` ([`9147dad`](https://github.com/plexusone/omnidevx/commit/9147dad))

### Dependencies

- Bumped `github.com/plexusone/omnidevx-core` from v0.3.0 to v0.4.0 and `github.com/plexusone/omni-openai` from v0.6.1 to v0.7.0 ([`6d68303`](https://github.com/plexusone/omnidevx/commit/6d68303))
- Bumped `github.com/grokify/gogithub` from v0.17.0 to v0.18.0 ([`3e52a9e`](https://github.com/plexusone/omnidevx/commit/3e52a9e))

### Documentation

- Added a Sessions user guide and a Sessions design page, and described session recovery in the README and docs home ([`8226cfb`](https://github.com/plexusone/omnidevx/commit/8226cfb))
- Pointed work tracking at VisionStudio in AGENTS.md ([`60191fa`](https://github.com/plexusone/omnidevx/commit/60191fa))

## [v0.1.0] - 2026-07-19

### Highlights

- Initial release: batteries-included distribution composing omnidevx-core, omni-github, and omni-openai behind one import path

### Added

- Re-exported canonical types, event/mode/severity constants, and provider constructors (Claude Code, Codex, git, GitHub) under a single `omnidevx` import path ([`20cd110`](https://github.com/plexusone/omnidevx/commit/20cd110))
- `NewDefault` for composing local Claude Code and Codex collectors against the current machine's default stores ([`20cd110`](https://github.com/plexusone/omnidevx/commit/20cd110))
- `Engine` runs an arbitrary set of `core.Collector`s over one request; one collector failing does not stop the others, and errors are joined with their source named ([`66ad85e`](https://github.com/plexusone/omnidevx/commit/66ad85e))
- `Events` flattens collection results from multiple collectors into a single event slice ([`66ad85e`](https://github.com/plexusone/omnidevx/commit/66ad85e))

### Dependencies

- `github.com/plexusone/omnidevx-core` v0.1.0 for the canonical event model ([`af19e93`](https://github.com/plexusone/omnidevx/commit/af19e93))
- `github.com/plexusone/omni-github` v0.5.0 for the GitHub DevX collector ([`af19e93`](https://github.com/plexusone/omnidevx/commit/af19e93))
- `github.com/plexusone/omni-openai` v0.6.0 for the Codex CLI collector ([`af19e93`](https://github.com/plexusone/omnidevx/commit/af19e93))

### Documentation

- README documenting the batteries-included distribution, the OmniDevX/OmniDXI distinction, available collectors, and usage examples ([`57753a8`](https://github.com/plexusone/omnidevx/commit/57753a8))
- README shields for CI, lint, SAST, godoc, mkdocs, visualization, and license ([`233ef90`](https://github.com/plexusone/omnidevx/commit/233ef90))
- Fix README badges that pointed at omnidevx-core instead of omnidevx, and update the Collectors table to include Git and GitHub ([`1625a5e`](https://github.com/plexusone/omnidevx/commit/1625a5e))
- MkDocs site (Material theme, matching omni-github/omni-openai/omnidevx-core) with a home page, Collectors reference, and v0.1.0 release notes ([`b1bdcbc`](https://github.com/plexusone/omnidevx/commit/b1bdcbc))

### Tests

- Multi-collector aggregation, per-collector failure isolation with error joining, Add/Collectors chaining, context cancellation, and provider-constructor composition tests ([`fb8fb75`](https://github.com/plexusone/omnidevx/commit/fb8fb75))

### Infrastructure
